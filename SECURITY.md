# Security policy

## Reporting a vulnerability

Please report security problems privately. Use the **Report a vulnerability** button on the Security tab of this repository, which sends the report to the maintainer without making it public. Don't post details in a public issue or pull request.

Include what you found, how to reproduce it and which version you tested. If you want credit in the fix, say so.

## Supported versions

Fixes go into the latest release only.
